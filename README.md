# naygalwebsite

Il s'agit du site web du projet nayagl et naygal academie.

Ce projet a été initialisé avec [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

Pour démarrer le serveur de développement :

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

## PassAcad

Le test étudiant est généré, corrigé et affiché dans le navigateur. Aucune réponse, aucun score ni
aucune tentative PassAcad n’est envoyé ou enregistré par le serveur. Le résultat est indicatif et
peut être modifié dans le navigateur ; la validation finale de l’adhésion reste effectuée par l’équipe.
